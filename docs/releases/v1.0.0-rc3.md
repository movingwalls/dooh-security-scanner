# DOOH Security Scanner v1.0.0-rc3 (release candidate)

Self-contained downloads for every mainstream platform, and Nuclei is now fetched as the latest release for your machine.

> **Release candidate.** A PASS means "none of these checks matched", not "secure".
> **Only scan devices you own or are authorised to test.**

## Download
Each self-contained download includes the scanner, its own Java runtime (nothing to install), Nuclei and the templates.

| File | For |
|---|---|
| `dooh-security-scanner-1.0.0-rc3-windows-x64.zip` | Windows 10/11 (Intel/AMD). Run `dooh-security-scanner.exe -t targets.txt` |
| `dooh-security-scanner-1.0.0-rc3-linux-x64.tar.gz` | Linux, Intel/AMD. Run `./dooh-security-scanner -t targets.txt` |
| `dooh-security-scanner-1.0.0-rc3-linux-arm64.tar.gz` | Linux, 64-bit ARM (Raspberry Pi 4/5, Graviton, ...) |
| `dooh-security-scanner-1.0.0-rc3-macos-x64.tar.gz` | Mac, Intel |
| `dooh-security-scanner-1.0.0-rc3-macos-arm64.tar.gz` | Mac, Apple Silicon |
| `dooh-security-scanner-1.0.0-rc3.zip` | Any other system with Java 17+: jar, templates, launchers and docs |
| `dooh-security-scanner-1.0.0-rc3.jar` | Just the jar (Java 17+). Templates are packaged inside |

Verify with the `.sha256` file next to each download. **macOS:** these builds are not Apple-notarized; after extracting, run
`xattr -dr com.apple.quarantine dooh-security-scanner-1.0.0-rc3` once. If your antivirus blocks `nuclei.exe`, add it to the allowlist.

## What changed
- Self-contained bundles for Windows x64, Linux x64/arm64 and macOS Intel/Apple Silicon (the Windows file is now `...-windows-x64.zip`).
- When Nuclei is needed and not found, the scanner downloads the **latest** release for your OS/CPU, verified against the checksum
  published with that release; if that lookup fails it uses the tested version (3.4.10). New `--nuclei-version`; `--install-nuclei` updates to the latest.
- Releases are published only after the tests pass on Linux x64/arm64, macOS Intel/Apple Silicon and Windows.
