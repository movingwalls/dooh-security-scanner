# DOOH Security Scanner v1.0.0-rc1 (release candidate)

> **Superseded: do not use. Upgrade to v1.0.0-rc3 or later.** This release runs a `nuclei` / `nuclei.exe` and loads `templates/` found in the folder the scanner is started from (see [SECURITY.md](../../SECURITY.md)).

A free, open-source perimeter check for digital out-of-home (DOOH) screens. Give it a list of IP addresses; it
reports **PASS / REVIEW / FAIL** for each, with evidence and a recommended fix. Built on
[Nuclei](https://github.com/projectdiscovery/nuclei); everything runs on your own machine.

> **Release candidate.** Unit tests, template lint and CI checks pass; verification on real NovaStar,
> Colorlight, Huidu and Android devices is in progress ([docs/TESTING.md](docs/TESTING.md)). A PASS means
> "none of these checks matched", not "secure". **Only scan devices you own or are authorised to test.**

| `dooh-security-scanner-1.0.0-rc1.zip` | Any OS with Java 17+. Nuclei v3.4.10 is downloaded automatically (checksum-verified) on first use |

Verify with the `.sha256` file next to each download. If your antivirus blocks `nuclei.exe`, add it to the allowlist.

## Highlights
- **Detection only by default.** Default-password checks run only with `--intrusive` and the owner's consent.
- **Automatic setup.** Nuclei is fetched from ProjectDiscovery's official release when missing, verified against a
  SHA-256 built into the scanner, and cached per user. The templates are packaged in the jar.
- **Honest results.** A template that fails to load gives **ERROR**, never PASS. Reports include evidence and a
  fix per finding as text, HTML and JSON, mapped to the OWASP IoT Top 10.
- **Safe by design.** Targets are validated and never passed through a shell; fixed rate limits protect fragile
  LED controllers; only this project's templates run; discovery shows the network and asks first.

## What changed since the first internal build
**Fixed**
- 5 templates that did not load; 4 that matched ordinary web servers (Samsung VXT, NovaStar favicon, config
  exposure, default login); a malformed ADB handshake.
- A broken template was reported as PASS.
- Command injection through `targets.txt`.
- Discovery picking up multicast addresses, VPN/virtual adapters, and assuming a /24.
- Lost evidence, hard-coded `C:\Users\...` paths, inconsistent `[Fail]`/`[PASS]` output.

**Added**
- Automatic Nuclei install, single-jar use, HTML report, Windows native bundle, Ctrl+C handling.
- README, security policy, contributing guide, code of conduct, issue/PR templates, legal and
  fix-it docs, CI with template validation and a false-positive check.

**Changed**
- Licence is now **Apache-2.0** (was GPL-3.0).
- Templates are grouped by platform, carry remediation text and use `movingwalls` as author.

**Removed**
- Developer leftovers (`scanner.bat`, `config.txt`, home-network IPs, Eclipse files).

See the full [CHANGELOG](CHANGELOG.md).

## Known limitations
- Real-device verification is still in progress.
- Covers the DOOH devices and services listed in the README only: no firmware/CVE checks, CMS servers,
  LG webOS, BrightSign or router configuration tests.
- A finding from inside your network does not by itself prove internet exposure; see
  [docs/FIXING-FINDINGS.md](docs/FIXING-FINDINGS.md).
- Windows 10/11 64-bit is officially supported; Linux and macOS are best effort.
