# DOOH Security Scanner v1.0.0-rc2 (release candidate)

> **Superseded: do not use. Upgrade to v1.0.0-rc3 or later.** This release runs a `nuclei` / `nuclei.exe` and loads `templates/` found in the folder the scanner is started from (see [SECURITY.md](../../SECURITY.md)).

Same scanner as rc1, with one packaging change: the **single jar is now published as its own download**.

> **Release candidate.** A PASS means "none of these checks matched", not "secure".
> **Only scan devices you own or are authorised to test.**

## Download
| File | For |
|---|---|
| `dooh-security-scanner-1.0.0-rc2-windows.zip` | **Windows 10/11 (recommended).** Includes the app, its own Java runtime, Nuclei and templates. Extract, then run `dooh-security-scanner.exe -t targets.txt` |
| `dooh-security-scanner-1.0.0-rc2.zip` | Any OS with Java 17+: jar, templates, launchers and docs |
| `dooh-security-scanner-1.0.0-rc2.jar` | Just the jar (Java 17+). Templates are packaged inside; Nuclei v3.4.10 is downloaded automatically (checksum-verified) on first use |

Verify with the `.sha256` file next to each download. If your antivirus blocks `nuclei.exe`, add it to the allowlist.

See the full [CHANGELOG](CHANGELOG.md) and [docs/TESTING.md](docs/TESTING.md) for verification status.
