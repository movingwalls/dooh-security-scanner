dooh-security-scanner
---------------------
dooh security scanner, checks for exposure of admin panels, login panels etc. and prints vulnerability report


1. Ensure Java runtime is installed by searching for "get java" and install java version 11 and above
2. There are 2 ways to run this app

Way 1 (For known ip addresses:

1.1 Open targets.txt and type in ip address one per line and save it
1.2 and double click  dooh-security-scanner-easy.bat

Way 2:

2.1 Double click dooh-security-scanner-discover-easy.bat
