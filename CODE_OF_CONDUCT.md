# Code of conduct

We want this project to be a welcoming, professional place for people who care about securing digital
out-of-home screens.

**Expected:** be respectful and constructive; assume good faith; give and accept feedback graciously;
focus on what is best for the community and the users of the tool.

**Not acceptable:** harassment, discrimination, personal attacks, trolling, publishing others' private
information, and anything that uses this project to attack systems you are not authorised to test.

**Scope and enforcement:** this applies in all project spaces (issues, pull requests, discussions). Maintainers
may remove comments, close issues or ban contributors who breach it. Report concerns privately to
**security@movingwalls.com**. Reports are handled confidentially.

This text is inspired by the Contributor Covenant (https://www.contributor-covenant.org).
